# Task 2: SQL Data Analysis and Python Integration

## Objective
The objective of this task is to perform SQL-based data analysis on a dataset stored in MySQL and integrate SQL with Python using SQLAlchemy and Pandas.

## Tools & Technologies
- Python
- MySQL Workbench
- SQLAlchemy
- Pandas
- PyMySQL
- VS Code

## Tasks Performed

### SQL Fundamentals
- Imported the dataset into MySQL.
- Executed basic SQL queries:
  - SELECT
  - WHERE
  - ORDER BY
  - GROUP BY
  - HAVING
  - LIMIT
  - Aggregate Functions (COUNT, SUM, AVG, MAX, MIN)

### Advanced SQL
- Created SQL Views.
- Used aggregate functions for data analysis.
- Generated category-wise sales summaries.
- Performed business-related SQL queries.

### Python + SQL Integration
- Connected Python with MySQL using SQLAlchemy.
- Retrieved data using `pandas.read_sql()`.
- Executed SQL queries directly from Python.
- Displayed query results in the console.

## Business Questions Solved
1. Number of orders by category.
2. Top categories by total sales.
3. Highest value orders.
4. Category-wise total sales.
5. Average order value by category.
6. Maximum order amount by category.
7. Minimum order amount by category.
8. Categories with highest sales.
9. Total number of orders.
10. Category-wise sales summary.

## Project Files

- `python_sql_integration.py` – Python script for database connectivity and SQL execution.
- `db_utils.py` – Reusable database connection utility.
- `task2.sql` – SQL queries used in this task.
- `README.md` – Project documentation.

## Outcome
Successfully connected Python with MySQL, executed SQL queries from Python, and analyzed the dataset using SQL and Pandas.
